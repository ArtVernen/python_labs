## 1 Задание

Все функции находятся в файле `src/lib/text.py`.

### `normalize`

Приводит текст к нижнему регистру, заменяет `ё` на `е`, управляющие ASCII-символы на пробелы и удаляет лишние пробелы.

```python
import re


def normalize(text, *, casefold=True, yo2e=True):
    """Приводит текст к нижнему регистру и убирает лишние пробелы."""
    if casefold:
        text = text.casefold()
    else:
        text = text.lower()

    if yo2e:
        text = text.replace("ё", "е")

    text = re.sub(r"[\x00-\x1f\x7f]", " ", text)
    return " ".join(text.split())
```

**Как работает:** `casefold()` (или `lower()`) понижает регистр. `replace()` заменяет букву `ё`. `re.sub()` заменяет управляющие символы пробелами, а `split()` и `join()` оставляют по одному пробелу между частями текста.

**Пример:** `normalize("  ПрИвЕт\n ЁЖИК!  ")` → `"привет ежик!"`.

### `tokenize`

Разбивает текст на отдельные слова с помощью регулярного выражения. Поддерживает буквы, цифры, нижнее подчёркивание и слова с внутренним дефисом.

```python
def tokenize(text):
    """Находит слова, в том числе с дефисом."""
    return re.findall(r"\w+(?:-\w+)*", text)
```

**Как работает:** `re.findall()` находит все слова. `\w+` обозначает последовательность букв, цифр или `_`, а `(?:-\w+)*` разрешает части слова с дефисами.

**Пример:** `tokenize("Привет, кто-то пришёл!")` → `['Привет', 'кто-то', 'пришёл']`.

### `count_freq`

Подсчитывает количество повторений каждого слова в списке. Возвращает словарь: ключ — слово, значение — количество его повторений.

```python
def count_freq(tokens):
    """Считает количество повторений каждого слова."""
    freq = {}

    for word in tokens:
        freq[word] = freq.get(word, 0) + 1

    return freq
```

**Как работает:** создаём пустой словарь `freq`. Для каждого слова `get(word, 0)` берёт прежнее количество повторений или ноль, если слова ещё нет. Затем прибавляем единицу.

**Пример:** `count_freq(["кот", "пёс", "кот"])` → `{'кот': 2, 'пёс': 1}`.

### `top_n`

Возвращает список из N наиболее частых слов. Сортировка выполняется по убыванию частоты, а при одинаковой частоте — по слову.

```python
def top_n(freq, n=5):
    """Возвращает N самых частых слов."""
    return sorted(freq.items(), key=lambda x: (-x[1], x[0]))[:max(0, n)]
```

**Как работает:** `freq.items()` даёт пары `(слово, частота)`. `sorted()` сортирует их, `-x[1]` ставит большие частоты первыми, `x[0]` упорядочивает слова с одинаковой частотой. Срез `[:max(0, n)]` оставляет первые N пар.

**Пример:** `top_n({"кот": 3, "пёс": 2, "рыба": 1}, 2)` → `[('кот', 3), ('пёс', 2)]`.

### `text_stats`

Программа находится в `src/lab03/text_stats.py`. Получает строку из стандартного ввода, выводит количество всех слов, количество уникальных слов и пять наиболее частых слов.

Использует функции `normalize`, `tokenize`, `count_freq` и `top_n` из `lib/text.py`.

```python
def main():
    text = input()
    words = tokenize(normalize(text))
    freq = count_freq(words)

    print("Всего слов:", len(words))
    print("Уникальных слов:", len(freq))
    print("Топ-5:")

    top = top_n(freq, 5)

    for word, count in top:
        print(f"{word}:{count}")
```

**Как работает:** `input()` читает строку. `normalize()` очищает текст, `tokenize()` находит слова, `count_freq()` считает повторения, а `top_n()` выбирает пять самых частых. `len(words)` считает все слова, `len(freq)` — уникальные.

**Запуск из корня проекта:**

```bash
echo 'Привет, мир! Привет!!!' | python src/lab03/text_stats.py
```

**Вывод при `TABLE_MODE = False`:**

```text
Всего слов: 3
Уникальных слов: 2
Топ-5:
привет:2
мир:1
```

### Задание со звёздочкой ★

Дополнительно реализован вывод частот слов в виде таблицы с автоматическим выравниванием столбцов.

Для включения используется переменная `TABLE_MODE = True` в `text_stats.py`. Для обычного вывода — `TABLE_MODE = False`.

```python
if TABLE_MODE:
    width = max([len("слово")] + [len(word) for word, count in top])

    print(f"{'слово':<{width}} | частота")
    print("-" * (width + 10))

    for word, count in top:
        print(f"{word:<{width}} | {count}")
```

**Как работает:** `width` — длина самого длинного слова или заголовка. Формат `:<{width}` выравнивает слова по левому краю, а `"-" * (width + 10)` создаёт разделительную линию.

**Пример таблицы:**

```text
слово  | частота
----------------
привет | 2
```
